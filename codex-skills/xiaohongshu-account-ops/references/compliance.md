# 合规风险词与场景库

本文件用于发布前风险筛查，不是“命中即违规”的静态黑名单。必须结合语境、账号类型、商业关系和平台当前规则判断；不得用谐音、缩写、符号或暗语规避审核。

## 使用方法

1. 检查标题、正文、图片文字、口播、标签、评论引导和外链信息。
2. 将问题标为：
   - `停止`：明显违法、有害、欺骗、侵权或试图规避平台治理，不发布。
   - `人工复核`：事实、授权、资质或规则状态不明确，取得证据后再决定。
   - `可继续`：事实可验证、边界清楚、表达与素材均有授权。
3. 词语命中只触发复核。不要把高风险说法换成同义暗语后继续发布。
4. 涉及广告、医疗健康、金融、法律、未成年人或实时政策时，发布前核对最新官方规则；无法核实时保持草稿并说明不确定性。
5. 仅产出草稿或用户禁止联网时，可将动态规则标为“条件通过”，同时列出发布前必须核对的官方入口；不得宣称已经完成最终合规确认。

## 必须停止的场景

- 违法犯罪、暴力恐怖、色情低俗、自伤诱导、毒品或危险挑战。
- 对未成年人进行性暗示、诱导私联、展示可识别隐私或鼓励危险行为。
- 仇恨、歧视、人身攻击、网暴、性别对立或煽动群体冲突。
- 伪造聊天记录、评价、成交、检测报告、证书、效果对比或用户案例。
- 搬运他人文字、图片、音乐、视频、人设或肖像，且没有授权或合理使用依据。
- 泄露住址、联系方式、证件、课表、实时位置、行程等个人信息。
- 通过变体字、拼音、emoji、二维码或暗语绕过限制。

## 高风险场景

### 绝对化与无法证明的承诺

风险信号包括“第一”“唯一”“最好”“百分百”“一定”“零风险”“永久”“人人适用”“全网最低”。

处理原则：

- 删除无法证明的排名和保证。
- 改成有范围、有时间、有条件且可核实的事实。
- 个人体验写清样本和边界，例如“这是我连续两周的个人记录，不代表所有人”。
- 数据、排名、价格和对比必须注明来源、时间和口径。

### 医疗、健康、减重与健身

风险信号包括“治愈”“根治”“药效”“替代治疗”“快速瘦 X 斤”“无副作用”“适合所有体质”。

处理原则：

- 不提供诊断、处方或保证结果，不暗示普通食品、课程或器材具有医疗功效。
- 不把个体前后对比当作普遍效果；避免制造身材羞辱或饮食焦虑。
- 可记录训练过程、动作要点、饮食选择和主观感受，并说明个体差异与安全限制。
- 出现疼痛、疾病、用药、受伤或极端减重时，转专业人士，不给自动化建议。

### 引流、交易与站外联系

风险信号包括联系方式、二维码、外链、群聊，以及“加 V”“看主页”“看置顶”“dd 我”“懂的都懂”等间接引导。

处理原则：

- 不用暗语替代直接引流。
- 仅使用平台当前允许的公开组件和交易路径，并确认账号具备相应权限。
- 未确认规则或权限时，删除相关 CTA，不猜测“这样写就安全”。

### 商业合作与比较宣传

- 披露赞助、赠品、佣金、品牌合作或其他利益关系。
- 不伪装成无利益关系的“自来水”体验。
- 不贬损、拉踩或虚构竞品缺陷；比较必须使用一致标准、可验证证据和明确时间。
- “官方认证”“专家推荐”“销量第一”等表述必须有真实、有效且允许公开使用的证明。

### 隐私、肖像与版权

- 校园、健身房、球场、餐厅和旅行内容需检查路人正脸、车牌、门牌、票据、定位和屏幕通知。
- 未经同意不公开同学、室友、教练、店员或陌生人的身份与对话。
- 使用音乐、图片、字体、影视片段和品牌素材前确认许可；不能确认时换成原创或获授权素材。
- AI 生成图片不得冒充真实顾客、真实事件或真实效果；平台页面要求标注时如实标注。

## 风险词改写原则

| 风险信号 | 不应做的事 | 更安全的处理 |
| --- | --- | --- |
| 第一、最好、唯一 | 换成“天花板”“封神”继续承诺 | 提供具体标准、范围和个人判断依据 |
| 100%、一定、零风险 | 换符号或谐音规避 | 删除保证，写清条件、限制与不确定性 |
| 治愈、根治、瘦 X 斤 | 改成暗示性疗效 | 删除功效承诺，只保留真实过程和安全边界 |
| 加 V、看主页、dd 我 | 换成 emoji 或拼音 | 删除引流，或使用已核准的平台内路径 |
| 亲测有效、专家推荐 | 无证据继续使用 | 给出可核验证据；没有证据则改为有限的个人体验 |
| 全网最低、官方同款 | 只加“可能”“据说” | 核对来源、日期、授权和比较口径，否则删除 |

## 发布前检查清单

- [ ] 标题、正文、封面、图片文字、标签和 CTA 表达一致，没有标题党或内容不匹配。
- [ ] 每个价格、数据、功能、排名、效果、案例和引述均可追溯。
- [ ] 个人体验没有被写成普遍结论，限制条件已说明。
- [ ] 商业关系、素材授权和 AI 生成情况已按当前要求披露。
- [ ] 没有站外引流暗语、虚假互动、诱导关注点赞收藏或有奖刷评。
- [ ] 没有隐私、未授权肖像、侵权素材、攻击性表达或危险示范。
- [ ] 高风险领域已由合适的人复核；动态规则已查看最新官方版本。
