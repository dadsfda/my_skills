## 选模板

| 目标 | 优先模板 | 适合证据 |
| --- | --- | --- |
| 承接搜索 | 问题解决型 | 步骤、截图、地点、价格与日期 |

## 通用发布包

每次至少交付：

1. 受众、目标动作、内容支柱。
2. 三个方向不同的标题。
3. 可直接粘贴的纯文本正文。
4. 相关标签、封面文案、配图清单或生成提示词。
5. 事实来源、风险点、需人工确认项。
6. 发布模式与发布后检查计划。

标题优先使用“具体人群 + 具体场景 + 明确价值”。封面文案保持一眼能读懂，通常用一句短语即可；字数是视觉建议，不是平台规则。

## 标题公式库

标题公式用于打开角度，不保证“爆款”。所有数字、周期、价格、排名、结果和身份必须真实。

### 情绪触发型

- `后悔没早点[真实动作]：原来[有限发现]`
- `相见恨晚，但[对象]最适合的其实是[人群]`
- `终于把[问题]弄明白了，关键不是[常见误区]`
- `有惊喜，也有劝退：[对象]的真实优缺点`
- `差点因为[误区]选错，最后我看了这[数量]点`

### 数字清单型

- `[数量]个真正用上的[物品/方法]，按场景分好了`
- `记录[周期]后，我留下了这[数量]条结论`
- `[预算]内的[主题]清单：必需、可选和不建议`
- `做[事情]前先确认这[数量]个条件`
- `同一问题的[数量]种解法，分别适合谁`

### 对比冲突型

- `[A]和[B]怎么选？同一标准实测后说结论`
- `[金额 A]和[金额 B]的差别，主要不在价格`
- `以前我看[旧标准]，现在更在意[新标准]`
- `省钱还是省时间？[场景]下的两种取舍`
- `买前最心动的是[特点]，用后最在意的是[特点]`

### 疑问好奇型

- `[对象]真的适合[人群]吗？先看[数量]个限制`
- `为什么同样是[行为]，体验差别这么大？`
- `[场景]是什么体验？我的真实记录和意外`
- `怎样在[限制]下完成[目标]？这是我的版本`
- `如果只能选一个，你更愿意放弃什么？`

### 身份与场景型

- `作为[真实身份]，我挑[对象]只看这[数量]点`
- `[真实身份]的一天：[具体矛盾]怎么安排`
- `适合[人群]的[内容]，不等于适合所有人`
- `早八 / 宿舍 / 球场：[场景]里的真实选择`
- `课多还想[目标]，我的最低可执行版本`

### 地点、预算与时间型

- `[地点范围][预算]内吃什么？按[标准]分组`
- `[时长]+[预算]，一次大学生周末路线实录`
- `[日期]实付[金额]：[对象]值不值得`
- `从学校出发，[时长]内能完成的[主题]`
- `只带[限制]去[目的地]，真正用上的东西`

### 风险标题改造

| 原始标题倾向 | 问题 | 改造方向 |
| --- | --- | --- |
| `这款一定要买` | 绝对化 | `更适合[人群]，但有[限制]` |
| `90%的人都做错` | 数据无来源 | `[场景]最常见的[数量]个错误` |
| `坚持 X 天变化太大` | 结果暗示 | `记录 X 天，我观察到什么、不能确定什么` |
| `平替完胜大牌` | 比较不公平 | `按同一标准比较，A/B 各适合谁` |
| `亲测有效` | 体验或功效可能不实 | `我在[真实周期]的个人记录` |

## 模板一：问题解决型

适用：明确搜索问题、教程、避坑。

标题骨架：

- `[人群/场景]遇到[问题]，我最后这样解决`
- `[地点/项目]怎么选？先看这[数量]个条件`
- `做[事情]前，我希望早点知道的[数量]件事`

正文结构：

1. 一句话说明问题和适用人群。
2. 交代自己的场景、预算或限制。
3. 按顺序给出步骤，每步说明“做什么、为什么、容易错在哪”。
4. 补充结果、成本、时间和不适用情况。
5. CTA：`你卡在哪一步？把场景说具体，我按这套方法帮你拆。`

必须核实：价格、营业时间、路线、产品功能、政策和第三方数据。

## 模板二：清单工具型

适用：美食、旅行、购物、宿舍生活、训练准备。

标题骨架：

- `[预算]以内的[场景]清单，按需求分好了`
- `[时间/地点]一页式准备清单`
- `不是越多越好：[场景]真正用得上的[数量]样`

正文结构：

1. 先说明筛选标准，不直接堆物品。
2. 按“必需 / 可选 / 不建议”或“省钱 / 省时 / 体验”分组。
3. 每项给一个选择理由和一个限制。
4. 用总预算、总时长或路线顺序收束。
5. CTA：`你会删掉哪一项，或者还缺什么？`

## 模板三：过程实验型

适用：健身、篮球训练、学习习惯、生活方式记录。

标题骨架：

- `我连续[时间]记录[行为]，变化最明显的是这[数量]点`
- `同一个[动作/习惯]练了[时间]，有效和没用的部分`
- `从[起点]到[当前状态]：我的真实过程和限制`

正文结构：

1. 说明起点、目标、周期和记录方法。
2. 展示关键过程，不只展示最好结果。
3. 分开写“观察到的变化”和“无法确定的原因”。
4. 写出受伤、时间、饮食、器材或环境限制。
5. CTA：`你更想看训练安排、动作细节，还是失败记录？`

禁止：把个人变化包装成普遍疗效，伪造前后对比，承诺体重或身体结果。

## 模板四：比较测评型

适用：购物选择、餐厅对比、旅行方案、运动装备。

标题骨架：

- `[A]和[B]怎么选？按[数量]个使用场景说清楚`
- `同预算实测：[A]适合谁，[B]适合谁`
- `买前最纠结的[数量]点，我用同一标准对比了`

正文结构：

1. 披露购买、借用、赠送或合作关系。
2. 先定义统一标准：价格、体验、耐用、便携等。
3. 分项呈现 A/B 的事实与主观感受。
4. 给出分人群结论，不宣布“唯一赢家”。
5. 写明测试时间、版本、地点和样本限制。
6. CTA：`你的预算和最看重的一项是什么？`

## 模板五：故事复盘型

适用：大学生活、旅行经历、篮球比赛、消费踩坑。

标题骨架：

- `那次[事件]后，我改变了一个习惯`
- `我以为[原判断]，结果真正的问题是[新发现]`
- `[场景]没按计划走，但这[数量]件事值得记录`

正文结构：

1. 用一个具体瞬间开场。
2. 交代冲突、选择和当时掌握的信息。
3. 写结果，也写自己的责任和局限。
4. 提炼可复用的判断标准。
5. CTA：`如果是你，当时会怎么选？`

注意：隐藏他人身份与隐私，不用冲突制造网暴。

## 模板六：选择讨论型

适用：需要真实评论样本的生活决策，不适合严肃健康、法律或人身争议。

标题骨架：

- `大学生的[场景]，你会选 A、B 还是 C？`
- `同样是[目标]，你更愿意省钱还是省时间？`
- `这件事我和室友意见相反，想听真实理由`

正文结构：

1. 给足决策背景，不断章取义。
2. 列出 A/B/C，第三项保留“看情况/其他方案”。
3. 每个选项写清代价，不诱导站队。
4. 先给自己的暂定选择和理由，降低空泛评论。
5. CTA：`选一个并说理由；有第三种方案也欢迎补充。`

禁止：性暗示、征友诱导、性别对立、羞辱审美、虚构争议、求关注点赞收藏，以及“只打一个字母”“评论区扣 1”等空评论设计。

## 可直接填充的整篇模板

下面的模板保留完整发布结构。只有 `[方括号]` 全部被真实素材替换后，才可进入发布门禁。

### A. 种草或劝退模板

```text
【标题】
[真实周期]使用记录：[产品]适合谁、不适合谁

【开头】
先说关系：[自购 / 借用 / 赠送 / 商业合作]。
我在[真实场景]用了[周期]，最满意的是[事实]，最劝退的是[事实]。

【基础信息】
产品与版本：[名称/型号]
购入渠道与日期：[信息]
当时实付：[金额]
主要用途：[场景]

【体验一】
场景：[什么时候、在哪里用]
观察：[可见事实]
感受：[主观判断]
限制：[什么情况下不成立]

【体验二】
场景：[...]
观察：[...]
感受：[...]
限制：[...]

【缺点】
我不能接受的是：[缺点及代价]
如果你最看重[标准]，建议先别买。

【适合与不适合】
更适合：[人群+条件]
不太适合：[人群+条件]

【结尾】
你的预算和主要使用场景是什么？我更想看不同需求下的选择理由。
```

图片页序：首图结论 → 产品与购买凭证脱敏 → 场景实拍 → 优点证据 → 缺点证据 → 适合人群。

```text
【准备】
工具/材料：[清单]

【步骤1：[动作]】
怎么做：[具体操作]
成功标志：[可检查结果]
容易错：[错误]

【步骤2：[动作]】
怎么做：[...]
成功标志：[...]
容易错：[...]

【步骤3：[动作]】
怎么做：[...]
成功标志：[...]
容易错：[...]

【失败补救】

```

图片页序：成果/问题 → 准备清单 → 每步一页 → 成功标志 → 失败补救 → 总结。

### I. A/B/C 选择讨论模板

```text
【标题】
[预算/时间]有限，你会选 A、B 还是 C？

【背景】
人群：[对象]
场景：[具体处境]
共同限制：[预算/时间/距离]

【A】
获得：[价值]
代价：[成本]

【B】
获得：[价值]
代价：[成本]

【C】
获得：[价值]
代价：[成本]

【我的暂定选择】
我会选[真实选项]，因为[本人确认的理由]。

【评论问题】
请选择并说明最关键的理由；有 D 方案也欢迎补充。
```

不要只让读者回复字母，也不要用虚构争议、性别对立或暧昧关系提高评论数。

## 图文页序模板

### 6 页教程

1. 结果或问题：读者将解决什么。
2. 前提与准备：适用人群、工具、费用和版本。
3. 第一步：动作与成功标志。
4. 第二、三步：关键操作。
5. 常见错误：失败表现与补救。
6. 总结：最小行动和具体提问。

### 6 页测评

1. 首图：对象、比较标准、有限结论。
2. 样品来源、日期、价格和测试方法。
3. A 的事实、优点、缺点。
4. B/C 按相同口径呈现。
5. 分人群选择，不设唯一赢家。
6. 限制、更新日期和讨论问题。

### 6 页生活记录

1. 真实场景或选择题。
2. 背景、预算和时间限制。
3. 过程一：照片证明什么。
4. 过程二：意外或失败点。
5. 本人判断与适用边界。
6. 开放问题，提醒保护隐私。

## 平台化表达检查

- 正文使用自然短段落，避免把 Markdown 表格、代码块或说明文字直接贴到平台。
- emoji 只辅助分段，不替代事实，也不堆满标题。
- 标签与内容强相关；不使用无关热词蹭流量。
- 评论问题应能用真实经验回答，不以冒犯、焦虑或对立换互动。
- 生成多个标题时让角度不同，而不是只替换同义词。
