# 运营指标与记录规范

## 最小发布记录

每次发布记录以下字段：

| 字段 | 说明 |
|---|---|
| `post_id` | 平台笔记 ID；未知时用稳定的本地 ID |
| `published_at` | 带时区的发布时间 |
| `url` | 可访问的笔记链接 |
| `pillar` | 内容支柱 |
| `format` | 图文、视频、清单、教程、案例等 |
| `title` | 最终标题 |
| `topic` | 标准化主题 |
| `cta` | 主要用户动作 |
| `publish_mode` | draft-only、confirm-before-publish 或 allowlist-auto |
| `evidence` | 发布成功截图或工具返回结果 |

## 表现指标

在可获得时记录：曝光或浏览、点赞、收藏、评论、分享、主页访问、关注增长、私信、线索、订单或到店。不要用估算值冒充平台数据。

建议至少在发布后 24 小时和 7 天记录快照：

| 字段 | 计算方式 |
|---|---|
| `engagement_rate` | `(点赞 + 收藏 + 评论 + 分享) / 曝光或浏览` |
| `save_rate` | `收藏 / 曝光或浏览` |
| `comment_rate` | `评论 / 曝光或浏览` |
| `follow_conversion` | `新增关注 / 主页访问`，仅在数据可得时计算 |
| `lead_conversion` | `有效线索 / 主页访问或私信`，分母需保持一致 |

分母为 0 或缺失时留空，不输出伪精确结果。

## 周度复盘

1. 按内容支柱、格式和发布时间分组。
2. 同时观察绝对量和比率，标注样本数。
3. 记录前三、后三内容及共同特征。
4. 区分内容质量、分发波动和数据缺失。
5. 输出最多三个单变量实验，并定义成功阈值。

## 结论等级

- 高置信：同类结果至少重复出现 3 次，且样本口径一致。
- 中置信：出现明确趋势，但样本较少或存在混杂因素。
- 低置信：来自单篇内容或不完整数据，只作为待验证假设。
