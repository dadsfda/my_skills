# Data Sources for Guangdong Gaokao Volunteer Planning

## Purpose

Use this reference whenever a Guangdong Gaokao volunteer task requires data, links, annual policies, admissions plans, historical admission comparison, or source-quality judgment.

## Source Priority

| Priority | Source | Use For | Notes |
|---|---|---|---|
| 1 | 广东省教育考试院 https://eea.gd.gov.cn/ | Annual policy,志愿填报通知,一分一段表,投档情况,征集志愿,专业目录更正 | Highest authority for Guangdong provincial rules and notices |
| 1 | 广东省普通高考报名/志愿系统 https://pg.eeagd.edu.cn/ks | Official fill-in portal, login and confirmation workflow | Never replace with a third-party portal |
| 1 | 教育部阳光高考平台 https://gaokao.chsi.com.cn/ | Admissions policies, university information, special admissions, public notices | Ministry-designated information platform |
| 1 | 招生章程库 https://gaokao.chsi.com.cn/zsgs/zhangcheng/ | Current-year university admissions charters | Verify major rules and restrictions |
| 1 | Target university official admissions website | University-specific charter, plan, campus, tuition, major adjustment, special rules | Use for cross-checking Sunshine Gaokao and provincial data |
| 2 | Current-year 广东招生专业目录 and 志愿填报指南 |院校专业组, major plan, tuition, campus,选科要求, batch | Use the version for the candidate category |
| 2 | Current-year 一分一段表 | Candidate position, score-to-rank interpretation | Rank is usually more useful than raw score |
| 2 | Recent Guangdong投档情况 | 2-3 year rank comparison | Check whether专业组 changed |
| 3 | City education bureaus / local admissions offices | Reposted provincial notices, local reminders | Use as backup only; trace back to province source |
| 3 | Third-party volunteer platforms, media, rankings, forums | Lead discovery, rough screening | Never cite as final authority |

## Required Annual Documents

For current-year planning, try to verify:

- Guangdong普通高校招生工作规定.
- Guangdong平行志愿投档及录取实施办法.
- Guangdong普通高考志愿填报通知.
- Guangdong普通高等学校招生专业目录 for the correct category.
- Guangdong普通高等学校志愿填报指南.
- Guangdong普通高考一分一段表.
- Recent投档最低分 and最低排位 for the same category.
- 专业目录增补、更正公告.
- 征集志愿通知 and缺额计划 if relevant.

## Cross-Checking Rules

- If a third-party page conflicts with an official source, trust the official source.
- If a university page conflicts with a provincial notice about Guangdong计划 or志愿 rules, cite the conflict and avoid a final recommendation until resolved.
- If Sunshine Gaokao and a university website differ on a charter detail, note both and recommend checking the university's latest published charter or admissions office.
- If historical专业组 codes or names changed, do not compare mechanically. Explain the limitation.
- If only scores are available and ranks are missing, say the recommendation is weaker and ask for rank or一分一段 context.

## Data to Record in Answers

For each concrete recommendation, record:

- Source name and URL.
- Publication date or document year.
- Candidate category and batch.
-院校专业组 code/name.
- Major list inspected.
- Plan count when relevant.
- Historical最低投档排位 and year.
- Eligibility checks completed.
- Remaining uncertainty.

## Red Flags

- "包录", "稳赚", "内部数据", or guaranteed admission language.
- Advice based on national rankings instead of Guangdong category/rank.
-专业组 recommendation without checking majors inside the group.
- Ignoring选科,体检,单科,外语语种,口试,政审/面试/体检 requirements.
- Treating old-year notices as current-year rules.
- Relying on screenshots without source URLs or document names.
